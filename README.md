# 🕹️ Hover Platform Game

A 2D platformer game built with **HTML**, **CSS**, and **JavaScript**, where players control a hovering character to across platforms, avoid falling, and reach the goal.

## 🎮 Live Demo

Play it now: [Hover Platform Game](https://petrabayu.github.io/hover-platform-game/)

## 🧩 Features

- **Simple Controls**: Use your mouse pointer to move from start point to finish.
- **Platformer Mechanics**: hover across platforms with mouse pointer to reach the goal.
- **Custom Physics**: Simulated gravity and hovering behavior using SCSS.
- **Minimalist Design**: Clean, retro-style visuals for smooth performance.

## 🛠️ Technologies Used

- **HTML**: Canvas or structural layout.
- **CSS**: Basic styling, layout, and platforms mechanics.
- **Vanilla JavaScript**: Rendering content.

## 🚀 Getting Started

To run the game locally:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/yourusername/hover-platform-game.git
   ```

2. **Navigate to the project folder**:

   ```bash
   cd hover-platform-game
   ```

3. **Open `index.html` in your browser**.
